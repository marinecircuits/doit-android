# Combined task filters

Submitting only one `#project` and one or more `@labels` opens matching tasks without creating a task. The same expression works after `/` while typing. Quotes support names containing spaces. Matches include the named project and its active descendants and require every label. Matching ignores case; unknown labels or projects return no results. Ordinary text and incomplete expressions remain capture text. Filters use the local cache offline and preserve task ordering.
