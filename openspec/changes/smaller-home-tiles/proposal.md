# Proposal

## Why

The user wants the project boxes on the home screen to be a little smaller.

## What Changes

Reduce the minimum height of home project tiles from 120dp to 104dp. Preserve their adaptive width, text, colors, touch behavior and subproject layout.

## Capabilities

### Modified Capabilities

- `project-navigation`: slightly shorter home tiles.

## Impact

One layout dimension; no data, API or navigation change.
