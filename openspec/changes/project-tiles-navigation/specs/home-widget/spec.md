# Spec Delta

## MODIFIED Requirements

### Requirement: Widget shortcuts
Tapping the widget's + button SHALL open the app on the main view with the capture box focused and the keyboard shown, so the task goes to the default project. Tapping a task title SHALL open the app.

#### Scenario: Add from widget
- **WHEN** the user taps + on the widget, even if the app was last left on a project screen
- **THEN** the app opens on the main view with the capture box focused and the keyboard visible
