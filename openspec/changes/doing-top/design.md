# Design

Derive the open doing task IDs from the existing label state, then select the first task using the same ordering as task lists. Build the shortcut from all open tasks, independent of the current project or label screen. It disappears when the label is unavailable or no open tasks are doing.

Place the clickable surface above capture; when it is the first element on home it owns the status-bar inset. Show the project name and, for multiple tasks, a localized count of the remaining tasks. A single task opens the existing edit sheet. Multiple tasks use the existing Review navigation. The existing snackbar still warns when a conflict appears or changes.
