# Visual design

- Graphite background, layered neutral surfaces, soft white text, and lime for primary actions and focus. Colors are consistent across Android versions instead of changing with wallpaper.
- A compact wordmark and local date introduce the home screen. Section labels and project counts establish hierarchy without adding navigation.
- Project cards use their server color as a dark tint, a small folder or shopping icon, and a subtle opening arrow. Project pages use a quieter version of that tint. Light mode retains pale project colors.
- Capture uses a rounded filled field and a distinct add/open button. Task cards separate completion, content, and scheduling while retaining accessible touch targets and completion semantics.
- Setup groups connection inputs in one card and offers expandable token instructions; missing-permission errors expand them automatically. Editing sheets scroll on smaller screens.

No new runtime dependencies, data migrations, network operations, or release workflow changes are required.
