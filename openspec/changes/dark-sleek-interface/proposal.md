# Dark, focused Doit interface

The Android app uses generic wallpaper colors and pale project tiles even in dark mode. Give it a consistent graphite and lime identity, with rich project tints, clearer hierarchy, and more comfortable task controls.

The update covers the home grid, quick capture, project and label screens, task cards, search, setup, and editing sheets. The app continues to follow the device's light/dark preference. Project colors still come from Vikunja; light mode retains the existing color lightening. Task, sync, credential, and navigation behavior stays the same.

Validate project text contrast at color extremes, run the existing test suite, and inspect the signed build in Waydroid before delivering it.
